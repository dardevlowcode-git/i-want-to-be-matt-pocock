# Working rules

- Reply in the user's language.
- Label every operation `[READ-ONLY]` or `[MODIFICATION]`.
- Do not run destructive commands without explicit confirmation.

## Memory

When the user says “remember…” or “from now on…”, write the rule to the right `AGENTS.md`:
- general rule (applies across projects) → the global file;
- project-specific rule → the `AGENTS.md` inside that project.

Write rules so they can be reused, not tied to a single case. Before adding one, check that an equivalent rule does not already exist; update it if it does.

During a retrospective, prefer this project's documents for project state, results, and learnings; leave general insights in chat and do not automatically update global `AGENTS.md`. An explicit request for a global update is a separate activity: if the file already exists, propose the change and agree on it before editing.
